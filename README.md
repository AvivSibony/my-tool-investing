# בוט מסחר דמו

בוט לחשבון **דמו בלבד** (ללא כסף אמיתי): סריקה יומית, בדיקה על נתוני עבר והתראות לטלגרם.
אין כאן ייעוץ השקעות, ותוצאות עבר אינן מבטיחות תוצאות עתידיות.

## שתי דרכים להשתמש

| דרך | מה מקבלים | מה צריך |
|---|---|---|
| **האפליקציה באינטרנט** (`index.html`) | מעבדה לבחירת אסטרטגיה והגדרות סיכון, על נתונים סינתטיים או נתונים שמדביקים | רק דפדפן |
| **הבוט במחשב** (`bot_server.py`) | נתוני שוק אמיתיים, סריקה יומית, בדיקה על 10 שנים, התראות בטלגרם | Python במחשב |

## האפליקציה באינטרנט

אחרי הפעלת GitHub Pages היא נפתחת בכתובת:
`https://שם-המשתמש.github.io/my-tool-investing/`

באייפון: פותחים בספארי, לוחצים על כפתור השיתוף ובוחרים **הוספה למסך הבית**.

## הבוט במחשב

התקנה והרצה (בטרמינל, בתיקייה של הפרויקט):

```
pip install -r requirements.txt
python bot_server.py --selftest
python bot_server.py --once
python bot_server.py --backtest SPY,QQQ,GLD
python bot_server.py
```

| פקודה | מה היא עושה |
|---|---|
| `--selftest` | מריצה בדיקות אוטומטיות |
| `--once` | סריקה אחת עכשיו |
| `--backtest SPY,QQQ,GLD` | בדיקה על 10 שנות נתוני עבר, אפשר כמה סימולים |
| בלי פרמטר | שרת מקומי וסריקה יומית אוטומטית, בכתובת `http://localhost:8000` |

## התראות בטלגרם (אופציונלי)

ממלאים `token` ו-`chat_id` בקובץ `config.json`, שנוצר בהרצה הראשונה של הבוט. הקובץ לא עולה לגיטהאב.

## קבצים

- `index.html`: האפליקציה באינטרנט
- `manifest.webmanifest`: מאפשר הוספה למסך הבית
- `bot_server.py`: הבוט המלא
- `trading_bot.py`: גרסה פשוטה לבדיקת אסטרטגיה אחת
- `icons/`: אייקונים (SVG, PNG ו-favicon)
